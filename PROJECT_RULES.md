# STRICT PROJECT RULES FOR YASIRJAMAL.COM

## 🚫 1. ZERO DASH / HYPHEN RULE (CRITICAL MANDATE)
- **NEVER use em-dashes (`—`, `&mdash;`), en-dashes (`–`, `&ndash;`), or connecting hyphens (` - `) in customer-facing website copy, titles, paragraphs, or headings.**
- Use clean periods `.`, commas `,`, bullets `•` / `&bull;`, or natural sentence flow instead.
- Examples:
  - ❌ *WRONG*: "Direct partnership with Senior Web Architect — Zero agency account managers"
  - ✅ *CORRECT*: "Direct partnership with Senior Web Architect. Zero agency account managers"
  - ❌ *WRONG*: "Since 2010 — I have partnered directly"
  - ✅ *CORRECT*: "Since 2010, I have partnered directly"
  - ❌ *WRONG*: "Client Outcomes — Faster Growth"
  - ✅ *CORRECT*: "Client Outcomes • Faster Growth"

---

## 🎯 2. CLIENT-CENTRIC VALUE PROPOSITION (NO DEVELOPER JARGON)
- **Never lead with developer jargon** (Astro static architecture, semantic HTML5, JSON-LD, Core Web Vitals) in primary hero sections or pitches.
- **Always focus on commercial outcomes**:
  - Direct 1-on-1 partnership with a Senior Web Architect (15+ Years UAE Experience)
  - Zero agency account managers, zero junior handoffs, zero middleman bloat
  - More inquiries, phone calls, and WhatsApp qualified leads
  - Outranking competitors on Google & ChatGPT (AI Search / GEO / AEO)

---

## 📱 3. MOBILE-FIRST UI INTEGRITY
- **Never make text/headers sticky on mobile screens.**
- Sidebars and scroll-spy menus must always be scoped with desktop prefixes (`lg:sticky lg:top-28`).
- Keep floating triggers minimalistic with white badges and official SVG icons.

---

## 🔒 4. CANONICAL & SITEMAP STANDARDS
- All URLs must use `https://yasirjamal.com/` (non-www, HTTPS, strict trailing slash).
- Every deployment must preserve `.htaccess` 301 redirects and valid XML sitemaps.
