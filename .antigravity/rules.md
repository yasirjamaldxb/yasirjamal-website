# COPYWRITING RULES FOR YASIRJAMAL.COM

## 🚫 ABSOLUTE BAN ON DASHES AND HYPHENS IN PROSE
- Never use em-dashes (`—`, `&mdash;`), en-dashes (`–`, `&ndash;`), or spaced hyphens (` - `) in website copy, headings, subtitles, or badges.
- Always use clean punctuation: periods `.`, commas `,`, or bullets `•` (`&bull;`).
